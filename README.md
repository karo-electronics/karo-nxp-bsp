## Ka-Ro NXP i.MX BSP ##

Ka-Ro flavoured NXP i.MX BSP release.

For documentation see our Yocto Guide: https://karo-electronics.github.io/docs/yocto-guide/index.html

## Setup (VS Code)

### Requirements

- Linux system (Ubuntu-based distribution recommended)
- Docker engine installed and running
- VS Code installed
- VS Code Dev Containers extension

### Instructions

1. Open this repository with VS Code
2. The Dev Containers extension should prompt you to reopen the directory in a Container
3. Open a terminal
4. Run `bitbake-setup init`
5. Choose the different configuration options as desired
6. Open the generated "bitbake.code-workspace" in your generated setup directory under "bitbake-builds"
7. (Optional) Install the recommended "Yocto Project BitBake" extension
